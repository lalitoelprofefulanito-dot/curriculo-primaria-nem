# Modelo de datos v1.0

## Catálogos
Fases, grados, campos formativos, ejes articuladores, contenidos, PDA, proyectos y propósitos.

## Relaciones
- grado → campo → contenido
- grado → campo → contenido → PDA
- proyecto → eje
- proyecto → campo
- proyecto → propósito
- proyecto → contenido
- proyecto → PDA (derivada y solo con contenido validado)

## Identificadores
Los IDs técnicos no sustituyen los textos originales. `#PDA` se conserva como dato original y no como llave única.
